# ~/stefan-mehnert

Quellcode von [stefan-mehnert.de](https://stefan-mehnert.de): eine Visitenkarte im Stil eines Terminals.

Reines HTML, CSS und JavaScript ohne Build-Schritt. GitHub Pages liefert den Branch `main` direkt aus.

| Datei | Inhalt |
| --- | --- |
| `index.html` | Startseite mit dem Terminal |
| `assets/terminal.js` | Befehle, Texte (de/en), Boot-Sequenz |
| `assets/style.css` | Tokens aus dem Design-System `~/stefan-mehnert` |
| `404.html` | Fehlerseite für alte Blog-Links |
| `impressum.html`, `datenschutz.html` | Rechtliches |
| `fonts/` | JetBrains Mono und IBM Plex Sans, selbst gehostet (SIL OFL 1.1) |
| `CNAME` | Custom Domain für GitHub Pages |

Lokal ansehen: `python3 -m http.server` im Repo-Verzeichnis, dann http://localhost:8000.
